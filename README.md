# reality-script

只做一件事的梯子脚本：**VLESS + XTLS-Vision + REALITY**（Xray-core）。
一条命令装好，一个命令管理，不装 nginx、不要域名、不要证书。

## 安装

用 root 登录服务器，运行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Frank683456/reality-script/main/install.sh)
```

全程不用回答问题。装完直接给出节点链接、二维码和 Clash 配置。

```
  [1/6] 检查系统 ................ ✓ Ubuntu 24.04.5 LTS · x86_64
  [2/6] 下载 Xray 26.10.31 ...... ✓ 官方校验码对上
  [3/6] 挑伪装网站 .............. ✓ www.cisco.com（握手 42ms）
  [4/6] 生成密钥和账号 .......... ✓ 端口 443
  [5/6] 放行端口、开加速 ........ ✓ 没开防火墙，不用放行 · BBR 本来就开着
  [6/6] 启动并自检 .............. ✓ 本机当客户端连自己，成功
```

**更新脚本**：管理界面里选「更新脚本」。

**从自己电脑上装**（服务器连不上 GitHub、或想一条命令装好几台时）：在本仓库目录运行 `bash deploy.sh root@服务器IP`，同一条命令再跑一次就是更新。

## 客户端

| 客户端 | 怎么用 |
|---|---|
| 小火箭 / v2rayN / v2rayNG | 扫二维码，或复制 `vless://` 链接导入 |
| Clash Verge / mihomo | 用脚本给的配置段，`support-x25519mlkem768: true` 那行别删 |
| sing-box 系（Hiddify、NekoBox、sing-box App） | 暂时连不上 Xray 26.9.9 及以后的服务端 |

> Xray 26.9.9 起，REALITY 服务端只认带抗量子密钥交换（X25519MLKEM768）的客户端。
> 脚本给出的配置都已带上；老客户端要先升级。

## 支持的系统

- Debian 12 / 13（11 已停止维护，能装但不再测试）
- Ubuntu 20.04 / 22.04 / 24.04 / 26.04
- x86_64、ARM64

## 安装选项（都可以不填）

| 选项 | 说明 |
|---|---|
| `--port 端口` | 默认优先 443（Xray 官方建议），被占就随机挑高位端口 |
| `--sni 域名` | 默认从候选名单里实测，挑合格里握手最快的 |
| `--name 名字` | 第一个账号的名字，默认「主账号」 |
| `--label 前缀` | 节点显示名前缀，默认按机房国家（如 US） |
| `--xray 版本` | 装指定版本 Xray，默认最新正式版 |
| `--offline 目录` | 离线安装：目录里放 `Xray-linux-64.zip`（或 ARM 版）和对应 `.dgst`，适合连不上 GitHub 的国内机器 |
| `-y` | 遇到提问一律按默认走 |

选项跟在安装命令后面，例如 `bash <(curl -fsSL …/install.sh) --port 8443`。

## 安全约定

- 只动自己装的东西：`/opt/reality`、`reality.service`、`/usr/local/bin/reality`，跟别的梯子脚本共存互不影响
- 不 kill、不停任何不是自己的进程和服务
- Xray 只从官方 GitHub 下载，SHA256 对不上就不装；升级前留旧版，可一键回退
- 改配置先过 `xray run -test`，重启后起不来自动换回上一份
- 服务用独立的低权限系统用户运行，配置文件只有 root 和它能读
- 不记访问日志；不许通过梯子访问服务器本机和内网
- 伪装网站按 Xray 官方建议：TLS 1.3 + 抗量子密钥交换 + HTTP/2，不走 Cloudflare，不用 apple / icloud / microsoft 和 .cn .ru .ir 域名
- 防火墙认得 ufw / firewalld / iptables；1Panel 管的防火墙和云服务商安全组会提示去面板 / 控制台放行
- 卸载只删自己装的东西，并列出删了什么
