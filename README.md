# reality-script

一条命令在自己的 VPS 上装好 **REALITY 梯子**（VLESS + XTLS-Vision + REALITY，Xray-core），
之后输入 `reality` 就能加人、删人、看流量、升级。

- **傻瓜式**：安装全程不用回答问题，端口、伪装网站、密钥全自动，装完直接出二维码
- **只做一件事**：只有 REALITY 一种协议，不装 nginx、不要域名、不要证书
- **不碰别的东西**：独立目录、独立服务，跟网站、面板、别的梯子脚本共存互不影响
- **改坏了自动救回**：每次改配置都先检查、再真连自检，不通就自动换回上一份

## 一、准备

- 一台**海外** VPS，系统是下面任意一种：
  - Debian 12 / 13
  - Ubuntu 20.04 / 22.04 / 24.04 / 26.04
  - CPU：x86_64 或 ARM64 都行
- 能用 **root** 登录（普通用户先运行 `sudo -i` 切成 root）
- 如果服务商有「安全组」，比如甲骨文、阿里云、腾讯云、AWS、谷歌云，先去控制台放行 **TCP 443**（脚本装完也会提醒）

## 二、安装

用 root 登录服务器，复制下面这一行，回车：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Frank683456/reality-script/main/install.sh)
```

大约一两分钟，你会看到：

```
  REALITY 一键安装  v1.0.2
  ──────────────────────────────────────────────
  [1/6] 检查系统 ............... ✓ Ubuntu 24.04.5 LTS · x86_64
  [2/6] 下载 Xray 26.10.31 ..... ✓ 官方校验码对上
  [3/6] 挑伪装网站 ............. ✓ www.cisco.com（握手 42ms）
  [4/6] 生成密钥和账号 ......... ✓ 端口 443
  [5/6] 放行端口、开加速 ....... ✓ ufw · 已开 BBR 加速
  [6/6] 启动并自检 ............. ✓ 本机当客户端连自己，成功
  ──────────────────────────────────────────────
  ✓ 装好了！以后随时输入 reality 打开管理界面
```

下面紧跟着就是第一个账号（名字叫「主账号」）的**节点链接、二维码和 Clash 配置**，直接拿去用就行，用法见下一节。

> 某一步失败的话，脚本会把装了一半的东西全部清掉，机器恢复原样，可以放心重试。

### 安装选项（都可以不填）

选项跟在安装命令后面，例如 `bash <(curl -fsSL …/install.sh) --port 8443 --name 小明`。

| 选项 | 说明 |
|---|---|
| `--port 端口` | 默认优先用 443（Xray 官方建议），被占了就随机挑一个高位端口 |
| `--sni 域名` | 指定伪装网站；默认从候选名单里实测，挑合格里最快的 |
| `--name 名字` | 第一个账号的名字，默认「主账号」 |
| `--label 前缀` | 节点在客户端里显示成「前缀-名字」，默认是机房所在国家，比如 `US-主账号` |
| `--xray 版本` | 装指定版本的 Xray，默认最新正式版 |
| `--offline 目录` | 离线安装，见[常见问题](#服务器在国内连不上-github) |
| `-y` | 遇到提问一律按默认走（适合自动化） |

## 三、手机 / 电脑怎么连

装完（或在管理界面选「1 查看节点」）会给出三样东西：

- **链接**：以 `vless://` 开头的一长串
- **二维码**：就是这条链接
- **Clash 配置**：给 Clash 系客户端用的一小段

| 设备 | 推荐客户端 | 怎么导入 |
|---|---|---|
| iPhone / iPad | **Shadowrocket（小火箭）** ✅ 已实测 | 扫二维码；或复制链接，打开小火箭会自动识别 |
| 安卓 | **v2rayNG**（用最新版） | 右上角 ➕ → 扫描二维码，或「从剪贴板导入」 |
| Windows | **v2rayN**（用最新版） | 复制链接 → 服务器 →「从剪贴板导入」 |
| Mac / Windows / Linux | **Clash Verge Rev**（它的内核 mihomo ✅ 已实测） | 用 Clash 配置，见下面 |

> ⚠️ **sing-box 系客户端（Hiddify、NekoBox、sing-box App）暂时连不上**新版 Xray 服务端。
> 原因是 Xray 26.9.9 起，服务端只认带「抗量子密钥交换」的客户端，这几个还没跟上。

### Clash Verge Rev 的用法

在 Clash Verge Rev 的「订阅」页新建一个**本地配置**，编辑文件，把下面整段贴进去，
再把 `proxies:` 下面那段换成脚本给你的 Clash 配置：

```yaml
mixed-port: 7890
mode: rule
proxies:
  # ↓↓↓ 把脚本给的那段（从 - name: 开始）贴在这里，替换掉下面这几行 ↓↓↓
  - name: "US-主账号"
    type: vless
    server: 你的服务器IP
    port: 443
    uuid: ……
    network: tcp
    udp: true
    tls: true
    flow: xtls-rprx-vision
    servername: ……
    client-fingerprint: chrome
    reality-opts:
      public-key: ……
      short-id: ……
      support-x25519mlkem768: true
proxy-groups:
  - name: 代理
    type: select
    proxies:
      - "US-主账号"        # ← 改成你的节点名（跟上面 name 一样）
rules:
  - GEOIP,CN,DIRECT
  - MATCH,代理
```

> **`support-x25519mlkem768: true` 这一行千万别删**，删了就连不上新版服务端。

## 四、日常管理

登录服务器，输入：

```bash
reality
```

打开的管理界面长这样（实际是彩色圆角框）：

```
  REALITY 管理                                     v1.0.2
  ────────────────────────────────────────────────────────
  状态   运行中，已连续运行 12 天
  内核   Xray 26.10.31（最新）
  端口   443       伪装   www.cisco.com
  用户   5 个      今日   3.2 GB
  ────────────────────────────────────────────────────────
    1  查看节点              链接 / 二维码 / Clash 配置
    2  用户管理              加人 / 删人 / 看每人流量
    3  换端口 / 伪装网站
    4  更新 / 回退 Xray
    5  启动 · 停止 · 重启 · 日志
    6  更新脚本
    7  卸载
    0  退出
```

输入数字回车就行。在子菜单里直接回车 = 返回上一层。

### 给朋友开账号（每人一个）

`2 用户管理` → `1 加人` → 输入名字（中文英文都行）→ 马上给出这个人的链接和二维码，发给他就行。

- **每个人一个账号**，好处是能看每人用了多少流量，谁不用了单独删掉，不影响别人
- `2 删人`：选人、确认，**他的链接立刻失效**，其他人照常用
- `3 看某人的节点`：再看一遍某人的链接 / 二维码
- 用户管理页最上面就是每人**今天**和**本月**的流量（每小时自动记一次，重启也不丢）

### 换端口 / 换伪装网站

`3 换端口 / 伪装网站`：

- `1 换端口`：直接回车 = 自动挑（优先 443），也可以自己输
- `2 换伪装网站`：可以让脚本重新自动挑，也可以自己输一个域名；不合格的网站会被拒绝，并告诉你原因
- `3 改节点名前缀`：只改客户端里显示的名字

> ⚠️ 换端口、换伪装网站以后，**所有人的链接都会变**，要在「1 查看节点」里重新发给大家。

### 启动、停止、看日志

`5 启动 · 停止 · 重启 · 日志`：

- `6 自检`：服务器自己当一次客户端，真连一遍，最快判断「服务器这边有没有问题」
- `4 看最近的日志` / `5 实时看日志`（按 Ctrl+C 退出）
- 开机会自动启动，不用管

## 五、升级 Xray 内核

管理界面最上面「内核」那一行，有新版会显示 **（有新版 x.x.x）**。

**升级步骤**：`reality` → `4 更新 / 回退 Xray` → `1 更新到最新正式版` → 确认。

脚本会依次：

1. 从 Xray 官方 GitHub 下载新版，**核对官方校验码**，对不上就不装
2. 先用新版检查一遍现在的配置，不认就不换
3. 换上新版 → 重启（断几秒）→ **自动真连自检**
4. 自检不通 → **自动换回旧版**；通了 → 旧版留着，随时可以回退

其他选项：

- `2 回退到上一个版本`：新版有问题，一键换回去
- `3 装指定版本`：输入版本号，比如 `26.10.31`

> ⚠️ **升级前先看一眼大家的客户端**：Xray 从 26.9.9 起，服务端只认带「抗量子密钥交换」的客户端。
> 用这个脚本给的链接 / Clash 配置的都没问题；如果有人还在用很老的客户端，或者 sing-box 系客户端，升级后会连不上，先让他们换成第三节里的客户端。
>
> 脚本**从不自动升级**内核，什么时候升由你决定。

## 六、升级脚本

**升级步骤**：`reality` → `6 更新脚本`。

- 从本仓库下载最新版，检查完整无误才替换
- **账号、配置、流量记录都不动**，梯子不断
- 已经是最新会直接告诉你
- 脚本同样**从不自动更新**

> 另一种办法（适合一次管好几台）：在自己电脑上下载本仓库，运行
> `bash deploy.sh root@服务器IP`。没装过就安装，装过就提示更新，再进管理界面。

## 七、卸载

`reality` → `7 卸载` → 确认。

会删掉：服务、程序、配置、所有账号、流量记录、管理命令、本脚本加的防火墙规则和系统用户，最后列一张清单告诉你删了什么。
安装时顺手补装的小工具（比如 jq、qrencode）会留着，别的程序可能也在用。

## 八、常见问题

### 装好了，但手机连不上

按顺序查：

1. **服务商安全组**：甲骨文、阿里云、腾讯云、AWS、谷歌云这类，要去网页控制台放行 **TCP 端口**（装完提示里写了是哪个端口）
2. **1Panel 面板**：如果服务器装了 1Panel 并且它管着防火墙，要在面板「主机 → 防火墙」放行这个端口（脚本会提醒）
3. **服务器自己有没有问题**：`reality` → `5` → `6 自检`。自检通 = 服务器没问题，问题在网络或客户端
4. **客户端**：用第三节推荐的客户端最新版；Clash 记得那一行 `support-x25519mlkem768: true`

### 443 端口被网站占了怎么办

不用管，脚本会自动换一个高位端口，装完会告诉你用的是哪个。想指定就用 `--port`。

### 服务器在国内，连不上 GitHub

两种办法任选：

- **从自己电脑推过去**：下载本仓库，运行 `bash deploy.sh root@服务器IP`
- **离线包**：在能上 GitHub 的电脑上，从 [Xray 发布页](https://github.com/XTLS/Xray-core/releases) 下载 `Xray-linux-64.zip` 和 `Xray-linux-64.zip.dgst`（ARM 机器下 `Xray-linux-arm64-v8a` 那两个），连同 `install.sh` 一起传到服务器同一个目录，然后运行 `bash install.sh --offline 那个目录`

> 国内服务器会自动只挑境外 CDN 上的伪装网站。

### 机器上已经有别的梯子脚本（比如八合一脚本），能一起装吗

能。安装时会提示一句，确认后另开独立目录、独立端口、独立服务，跟原来的互不影响；卸载也只删自己的东西。

### 流量统计怎么算的

每个账号分开算，上传 + 下载，按服务器所在时区的日期记。每小时自动记一次，进管理界面时也会刷新一次。只保留最近两个月。

## 九、安全与隐私

- **不往外发任何东西**：运行时只连 Xray 官方 GitHub（下载内核）、查本机公网 IP 的网站、候选伪装网站（检测能不能用）、自检用的测速网址；账号、密钥、配置一样都不往外传
- **不记访问日志**：谁上了什么网站不落盘，只记出错信息
- **只动自己装的东西**：`/opt/reality`、`reality.service`、`/usr/local/bin/reality`；不停、不杀任何别的程序
- **内核只认官方**：Xray 只从官方 GitHub 下载，校验码对不上就不装
- **权限最小**：服务用独立的低权限系统用户运行，配置文件只有 root 和它能读；不许通过梯子访问服务器本机和内网
- **伪装网站按 Xray 官方建议挑**：TLS 1.3 + 抗量子密钥交换 + HTTP/2，不走 Cloudflare，不用 apple / icloud / microsoft 和 .cn / .ru / .ir 域名
- **从不自动更新**：内核和脚本都只在你手动点的时候才换
